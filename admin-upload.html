رفع صور العطور

اختر العطر من القائمة، ارفع صورته، والنظام يتكفّل بالباقي — اسم الملف، المكان الصحيح، كل شي تلقائي.

1) مفتاح الدخول (مرة وحدة بس بكل جلسة)

هذا المفتاح يبقى بمتصفحك فقط (بذاكرة الجلسة)، ما يترسل لأي مكان غير GitHub مباشرة، ويختفي لما تسكر التبويب. إذا ما عندك مفتاح: من حسابك بـ GitHub روح Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token، اختر الصلاحية بس على ريبو evoque-catalog، وامنحه صلاحية "Contents: Read and write". هذا المفتاح هو اللي يعطيك صلاحية الرفع — بدونه الصفحة نفسها ما تقدر تسوي شي حتى لو حد ثاني وصلها.
