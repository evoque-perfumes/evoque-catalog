لوحة تحكم منتجات Evoque

إضافة عطر جديد أو تعديل عطر موجود — الاسم، الأسعار، المخزون، والصورة — كل شي من مكان وحد، وينحفظ مباشرة على الموقع الحي.

ملاحظة: الشيت القديم (Google Sheet) ما عاد يتحدث تلقائيًا. من الحين، كل إضافة أو تعديل لازم تصير من هالصفحة فقط عشان يظهر بالموقع.

1) مفتاح الدخول (مرة وحدة بس بكل جلسة)

هذا المفتاح يبقى بمتصفحك فقط، ما يترسل لأي مكان غير GitHub مباشرة، ويختفي لما تسكر التبويب (إلا لو فعّلت "احفظ المفتاح"). إذا ما عندك مفتاح: من حسابك بـ GitHub روح Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token، اختر الصلاحية بس على ريبو evoque-catalog، وامنحه صلاحية "Contents: Read and write".

2) شنو تبا تسوي؟

عندك 182 عطر موجودين ببياناتهم كاملة أصلًا (من الشيت القديم) — كل اللي ناقصهم الصورة. استخدم "رفع صورة فقط" عشان ترفع الصور بسرعة بدون ما تفتح نموذج طويل. استخدم "تعديل بيانات عطر" بس لو تبا تغيّر سعر أو مخزون أو أي معلومة ثانية.
